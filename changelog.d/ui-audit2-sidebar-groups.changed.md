The sidebar is regrouped by what you are doing: MONITOR (Dashboard, Resources, Processes, Network Usage), DIAGNOSE (Hardware Info, Boot Analysis, System Logs), CLEAN (System Cleaner, Disk Tools, Disk Map, Mail Cleanup, File Shredder, File Search), MANAGE (Applications/Uninstaller, Startup Apps, Services, Homebrew/APT, Docker) and TOOLS (Helpers, GNOME Settings), with Settings and Feedback pinned below. "Search" is now "File Search" so it is not mistaken for the command palette. The Start Page list, Go menu shortcuts and tray follow the same order, groups you had collapsed stay collapsed, and navigating by shortcut or palette scrolls the sidebar to the selected page.
