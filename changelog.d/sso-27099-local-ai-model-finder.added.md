System Cleaner: "Deep clean → Local AI models…" lists the models downloaded by Ollama, Hugging Face, LM Studio and llama.cpp, one row per model with the bytes removal really frees (data shared between models counted once), when it was last used, and a heads-up about the re-download size and the owning tool's own list going stale. You pick what to remove; nothing is pre-selected and it never runs as part of a scan, schedule or background clean. Ollama models are removed with `ollama rm`; the rest go to the Trash and appear under History (SSO-27099). The store-layout logic is adapted from jithin-sabu/purge-app (MIT); see `THIRD_PARTY_LICENSES.md`.
