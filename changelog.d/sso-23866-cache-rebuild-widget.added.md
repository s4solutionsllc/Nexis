Helpers page (macOS, SSO-23866, part of the SSO-15367 Power Toolkit epic): a new **Cache Rebuild** card offers four independently-runnable actions — dyld shared cache, XPC cache, font cache (`atsutil databases -remove` + font-server restart), and Launchpad layout reset — each behind a confirmation dialog, with a per-step progress label while it runs and a clear ✓/⚠ result. Dyld shared cache is gated unavailable on macOS 11 (Big Sur) and later (the sealed system volume removed the manual rebuild path); XPC cache is gated unavailable on macOS 10.10 (Yosemite) and later (the on-disk xpcd cache was retired). Commands run through the existing `CommandUtil` exec wrapper, matching the SwappinessWidget/TrimWidget pattern rather than a new UI surface.
