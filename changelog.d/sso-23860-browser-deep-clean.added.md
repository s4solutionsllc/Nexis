Browser deep-clean engine (SSO-23860, Deep Cleaning Engine epic SSO-15366): `BrowserProfileLocator` (`shared/nexis-core/Utils/browser_profile_locator.h`) discovers installed Firefox and Chromium-family (Chrome, Chromium, Brave, Edge) browser profiles on Linux and macOS. `BrowserSqliteCleaner` (`shared/nexis/Managers/browser_sqlite_cleaner.h`) surgically deletes matched history/cookie rows from each profile's `places.sqlite`/`cookies.sqlite` (Firefox) or `History`/`Cookies` (Chromium-family) — never whole DB files — then `VACUUM`s, as a `TrustSafetyActionProvider` (SSO-15380) so it reuses the existing preview/confirm/cancel dialog with no new UI. A selective cookie keeper allowlist (exact host or subdomain match) excludes chosen domains from deletion. Refuses to run against a database currently held open for writing by a running browser instead of racing it. Not yet wired into a page — same follow-on status as SSO-23859's action interpreter.
