Duplicate Finder v2 (SSO-27146): a new **Duplicate folders** match mode finds whole folders with identical contents (e.g. two photo backups) and lists only the outermost match; **Replace with Links…** swaps ticked duplicates for hard links or relative symlinks after a preview, refusing cross-filesystem targets, re-checking file contents right before each swap and never leaving a path missing; and long scans can now be paused and resumed. Exact scans also stop counting names of one hard-linked file as reclaimable duplicates.
