Releases now include a native Debian 13 (trixie) `.deb` for amd64 and arm64 (`nexis_<version>-1_<arch>_debian13.deb`), so Debian 13 and Devuan 6 users can run `sudo apt install ./nexis_*_debian13.deb` instead of using the AppImage. It is built on `debian:trixie` against Qt 6.8, smoke-tested with `apt install` on a clean trixie in CI, and checksummed in `SHA256SUMS`. Debian 12 / Devuan 5 stay on the AppImage because bookworm's Qt 6.4 is below the Qt 6.8 floor (SSO-27438).
