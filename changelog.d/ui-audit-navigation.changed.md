Navigation overhaul. Settings is pinned to the sidebar footer instead of being the last row of a scrolling, collapsible group; collapsing a group and then the sidebar no longer hides that group's pages; the window title names the current page; page slides follow sidebar order. Added a menu bar (Settings ⌘, / View / Go with ⌘1–9 / Help) and shortcut hints now show the platform's real keys (⌘K rather than Ctrl+K on macOS). Esc is only captured while in kiosk mode, entering kiosk highlights Dashboard, the command palette runs a command on a single click and gained Feedback, Mini Monitor and a real "Run System Cleaner Scan", the tray gained Disk Map, Disk Map reuses one window, the Start Page list offers every page in sidebar order, and Settings, tab bars, Search, Processes and Homebrew controls are reachable by keyboard.
