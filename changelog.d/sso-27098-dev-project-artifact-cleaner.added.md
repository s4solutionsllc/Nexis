Disk Tools: new "Developer Projects…" cleaner (SSO-27098) finds code projects under folders you choose and offers their rebuildable folders (`node_modules`, Python virtual environments, `target`, `build`, `Pods`, `.gradle`) as one row per project, sized and aged by the project's own activity including git, not the folder's date. Nothing is pre-selected. Projects with a program running inside them or a git operation in progress are never listed, your home folder and system locations are refused, and everything is moved to the Trash. It is never part of scheduled or headless cleans.
