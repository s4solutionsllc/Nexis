Dialogs now use the same words in the same places. "Cancel" abandons a pending action, "Close" dismisses a view with nothing pending, and confirm buttons name what they do ("Save", "Shred", "Move to Trash", "Add Tile", "Import") instead of "OK". The leftover-review dialogs say "Cancel" rather than "Skip", button order follows the platform convention, dialog margins match, and pressing Enter never triggers a destructive button. Feedback and Exclusions no longer show orange or red buttons for plain choices, and screen readers no longer announce buttons as "primary" or "danger".
