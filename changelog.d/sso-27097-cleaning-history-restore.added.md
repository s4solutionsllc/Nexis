System Cleaner: new "History" view (Recently removed) listing every clean — manual, scheduled and background — with the paths it removed or skipped and the space freed. Items moved to the Trash (such as aged Downloads) can be restored from it; Restore refuses, with a clear message, if something already exists at the original location or the item is no longer in the Trash. Only metadata (paths, sizes, result) is recorded, never file contents, and the existing audit-log retention applies.
