System Cleaner (SSO-27101): new cleaning profiles for developer tools. `safe` (rebuilt on their own): uv and Poetry download caches, and editor caches for Cursor, VSCodium, Windsurf and VS Code Insiders. `aggressive` (skipped unless "Allow aggressive profiles" is on, because removing them forces a re-download or breaks the tool until reinstalled): conda/mamba package caches, Playwright, Cypress and Puppeteer browser downloads, the Terraform plugin cache, and the Dart/Flutter pub cache. Installed toolchains (pyenv, rustup, nvm, uv-managed Pythons, the Flutter SDK, Poetry virtual environments) are never touched.
