Settings → Migration gains **Export settings…** and **Import settings…** to back up or move Nexis to another machine (SSO-27150). The export is a versioned JSON file with your settings, cleaner exclusions and cleaning profiles; machine-specific state (window layout, sensor choices, usage history, schedules, auto-clean targets) is never included. Import shows a preview of what will change, reports unknown or invalid entries, and refuses files from a newer format version.
