System Cleaner (SSO-27096): bundled cleaning profiles now follow one rule — `safe` only if the owning app rebuilds the path on its own. Four profiles held paths that fail it, so those paths moved from `safe` to `aggressive` and are skipped unless "Allow aggressive profiles" is on: Gradle downloaded dependencies (`modules-*`, new `gradle-dependencies` profile), NuGet global packages (`~/.nuget/packages`, new `nuget-packages` profile), Yarn berry's global cache (`~/.yarn/cache`, `~/.yarn/berry/cache`, new `yarn-berry-cache` profile), and the whole Spotify profile, whose folders hold offline downloads. The remaining Gradle, NuGet and Yarn cache profiles stay `safe`. If you override one of these by `id` in your own profiles directory, your override still wins.
