Cleaning-profile safety checks and a "what Nexis touches" page (SSO-27096): a policy file (`shared/nexis/cleaning_profiles/safety_policy.json`) lists locations no bundled profile may touch (credentials, personal folders, installed toolchains, editor user data) and path classes a `safe` profile may not match (app settings, keys, history, databases, toolchains, offline data). A CI check fails on a violation, and `docs/WHAT_NEXIS_TOUCHES.md` is generated from the profiles and fails CI if stale.
