macOS: temperature sensors (and fans) were never detected on Apple Silicon because the AppleSMC request struct was 49 bytes instead of the 80 the kernel requires, and key size/type were read from a reply that leaves them zeroed; the layout is fixed, thermal discovery now walks the SMC key table for every `T*` temperature key instead of probing only `TC0P`/`TC0D`/`TG0P`, and fan RPM now decodes the little-endian `flt ` values Apple Silicon reports, so the Dashboard temp tile, avg/max summary and fan readout appear (SSO-27979).
