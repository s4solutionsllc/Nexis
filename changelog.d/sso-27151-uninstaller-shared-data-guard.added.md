The Uninstaller's leftover review no longer offers data that another installed app still uses. When removing an app, files that a still-installed sibling or channel variant also claims (for example `com.example.App.beta` caches when removing `com.example.App`, or the shared `firefox` profile while `firefox-esr` stays installed) are listed with a reason in a new Note column and can't be selected, on both macOS and Linux (SSO-27151).
