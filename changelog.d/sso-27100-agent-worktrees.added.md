Disk Tools: new "Agent Worktrees…" dialog finds git worktrees left behind by AI coding agents (Claude Code, Codex, Cursor, Paperclip) — ones whose folder is gone, whose repository no longer registers them, or that have sat idle for 30 days — and shows each one's uncommitted and unpushed work. Registered worktrees are removed with `git worktree remove` (git itself refuses any with uncommitted changes); folders git no longer knows about move to the Trash and can be restored from System Cleaner → History. Nothing is pre-selected, a worktree with a process running inside it cannot be selected, and the feature never runs from a scheduled or headless clean (SSO-27100).
