Contributors can regenerate every documentation screenshot with `nexis --capture-docs <repo-root>`: Nexis opens each page, sets up the documented state, captures the window itself (no screen-recording permission needed, works on Wayland) and writes the images under the file names the README, website guide and AppStream metadata already use. It runs in a throwaway profile by default, so your own settings and history are never touched. See `docs/SCREENSHOTS.md`.
