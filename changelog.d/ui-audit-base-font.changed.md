Text size is now consistent across the app. Pages and widgets the stylesheet did not size (Network Usage, Mail Cleanup, Helpers, Settings toggles, table rows, dialogs, tooltips) previously fell back to the platform default — 13pt on macOS — next to 9–10pt text elsewhere; everything now shares one 10pt base, panel titles and large values use shared styles, and the remaining pixel-sized fonts were moved to the point scale.
