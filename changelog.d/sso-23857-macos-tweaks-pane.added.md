Helpers (macOS, SSO-23857, part of the SSO-15367 Power Toolkit epic): a new "Tweaks" pane exposing hidden `defaults` preferences for Finder, Dock, Screenshots, Animations, and the login window (15 tweaks total) — following the existing Helpers-widget pattern (swappiness FR-81, TRIM FR-118, battery threshold SSO-3743) rather than a new UI. Each tweak shows its live current value (read via `defaults read`, falling back to a documented system default when unset), applies via `defaults write` plus the relevant `killall` (Finder/Dock/SystemUIServer), and has a one-click "Revert" action (`defaults delete`). A search box filters tweaks by name/category/description in real time. Tweaks with a minimum macOS version are hidden/disabled with an explanation instead of silently no-oping. Bool-typed tweaks also get a "Toggle" command in the command palette; non-bool tweaks get a "Reset to Default" command — both invocable without opening the pane. New cross-platform-compiled backend: `MacDefaultsTool` (argv-build/output-parse for `defaults`, unit tested), `MacTweaksCatalog` (the tweak definitions + toggle/reset orchestration, unit tested), `MacOsVersionUtil` (OS-version gating helper, unit tested).
