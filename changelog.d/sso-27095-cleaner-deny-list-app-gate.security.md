System Cleaner safety gates (SSO-27095): every System Cleaner delete — interactive, scheduled and headless `--clean` — now resolves the path (symlinks included) and checks it against the shared `LifecycleDenyList` hard-denied system locations and credential stores before removing anything, and skips application data (browsers, Slack, Discord, VS Code, Spotify, Zoom, Teams, Xcode and similar) while the owning app is running. Skipped paths are reported in the cleaner results, the Clean Selected dialog, `clean_history.log` and the scheduled-clean notification instead of being deleted. App Cleaners (CleanerML) re-check the deny-list and the running app right before each item, no longer empty the target of a symlink-to-directory, and refuse to truncate or VACUUM through a symlink. The change can only add skips; it never makes a clean delete anything it would not have deleted before.
