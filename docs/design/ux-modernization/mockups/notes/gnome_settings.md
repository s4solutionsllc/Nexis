**Corrected vs. the round-1 placeholder — the main round-2 finding:** round-1 guessed representative GNOME defaults (Color Scheme "Prefer Dark", GTK Theme "Adwaita-dark", UI/Document fonts "Cantarell", Monospace "Source Code Pro", Font Antialiasing "Subpixel (LCD)") with no live source. The live capture shows the CI container's actual gsettings state — plain GNOME/Adwaita defaults, not a dark-preferring desktop: Color Scheme "Default", GTK/Icon/Cursor Theme "Adwaita" (not "Adwaita-dark"), UI/Document/Monospace fonts "DejaVu Sans" / "DejaVu Sans" / "DejaVu Sans Mono" (not Cantarell/Source Code Pro), Font Antialiasing "Grayscale" (not "Subpixel (LCD)"). Cursor Size (24), Text Scaling Factor (1.00), Font Hinting ("Slight"), and the Interface toggles (Animations on, Hot Corners on) matched round-1's guesses and are now verified live rather than assumed.

**UNVERIFIED (residual):** the Window Manager / Mouse & Touchpad / Desktop tabs' content (not reachable — only Appearance is the default/checked tab, matching the live capture); the Clock & Status group's row values (Clock Format, Clock Show Seconds/Weekday, Show Battery Percentage) — the live capture's 1024x768 viewport cuts off after only the group's accent-bar header edge is visible, so these four rows are carried over unchanged from round-1's `.ui`-derived placeholder, not re-verified. A taller or scrolled capture would be needed to verify them; flagged here rather than silently treated as confirmed.

**Changes** (only the three approved dimensions):

1. Each Appearance-tab `QGroupBox` (`groupThemes`, `groupFonts`, `groupInterface`, `groupClock`) becomes one DS §2 elevated section card (`@cardBgElevated`, radius 12, 1px `@borderColor`, single container shadow alpha 90 / blur 26 / offset (0,2)). Source: DS §2 (`dashboard_tile_wrapper.cpp:107-130`, `utilities.h:21-32`); `.ui` group list (`gnome_appearance_tab.ui:27,103,250,285`).
2. Three-layer surface hierarchy — `@pageContent` behind the scroll, `@cardBgElevated` group cards, flat controls. Source: DS §1 (`values.ini:2,29,30`).
3. Every group card gets a DS §3 header (3px ≥18px `@accentColor` accent bar + group title). A page-level accent-bar header ("GNOME Settings" + "GNOME desktop preferences" source line) sits above the tab bar. Source: DS §3 (`metric_tile_base.cpp:255-307`).
4. Rows follow the DS §4 scale and GNOME boxed-list grouping/alignment [GNOME-HIG]: label left (9pt/600 `@color06`), control right — `@cardBg` combos and steppers. **Themes and Fonts group values now verified against the live capture** (see "Corrected vs. round-1" above); Interface toggles (Animations / Hot Corners, both on) verified live; Clock & Status group values remain the round-1 `.ui`-derived placeholder (see UNVERIFIED). Source: DS §4 (`style.qss:772-815`); `.ui` labels/controls (`gnome_appearance_tab.ui:33-338`).
5. The `.ui` `tabBarLayout` (`gnome_settings_page.ui:36-144`) renders as a tab strip — **Appearance** (checked, `@accentColor`) / Window Manager / Mouse & Touchpad / Desktop — above the section cards, matching the live capture's active tab. Source: `.ui` (`gnome_settings_page.ui:40-130`).

**Destructive controls:** none — no tab in the GNOME Settings `.ui` defines a `danger`-role or destructive control, so `@destructiveColor` (DS §5) is not used.

**Explicitly unchanged:** the Linux sidebar contents/order (SYSTEM section Docker → Helpers → System Logs → APT Repository Manager (badge now 1, corrected from round-1's invented 25) → **GNOME Settings** (highlighted) → Settings, per `app.cpp:244-270`, and "Uninstaller" rather than macOS's "Applications"); the tab set, the group set, every control type, and all labels.
