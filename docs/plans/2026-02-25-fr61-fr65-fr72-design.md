# Design: FR-61, FR-65, FR-72 — Symlink Cleanup, DNS Flush, Hardware Export

**Date:** 2026-02-25
**Status:** Approved

Three independent, low-complexity features implemented in a single batch.

---

## FR-61: Broken Symlink Cleanup

**Goal:** Add a 7th System Cleaner category that detects and removes broken symbolic links.

**Architecture:** Extends existing `CleanerService` category pattern. New enum value, scan method, and UI checkbox.

**Scan logic:**
- New `getBrokenSymlinks()` virtual method on `SystemInfo` base class with platform implementations
- `QDirIterator::Subdirectories` over conservative path set:
  - Both platforms: `~/.local/`, `~/bin/`
  - macOS: Homebrew prefix via `brew --prefix`
  - Linux: `/usr/local/bin/`
- Detection: `QFileInfo::isSymLink() && !QFileInfo::exists(symLinkTarget())`
- Deletion: `QFile::remove()` (removes link, not target)

**UI:** New checkbox + icon + label in System Cleaner category grid. Results in existing scan tree. New `c_symlink.svg` icon.

**Files:** `cleaner_service.h/.cpp`, `system_info.h`, both platform `system_info` impls, `system_cleaner_page.h/.cpp/.ui`, CMakeLists.txt, new SVG.

## FR-65: DNS Cache Flush

**Goal:** One-click DNS cache flush button on the Helpers page.

**Architecture:** Inline implementation in `HelpersPage` — no service class needed for a single command.

**Flow:**
1. Click "Flush DNS" button in nav bar
2. Confirmation dialog
3. Platform execution:
   - macOS: `dscacheutil -flushcache` + `sudo killall -HUP mDNSResponder`
   - Linux: detection chain: `resolvectl flush-caches` → `systemd-resolve --flush-caches` → `nscd -i hosts` → "not available"
4. Success/failure QMessageBox

**Platform branching:** `#ifdef Q_OS_MACOS` in `helpers_page.cpp`.

**Files:** `helpers_page.h/.cpp`, `helpers_page.ui`.

## FR-72: Hardware Report Export

**Goal:** "Export System Report" button on Hardware Info page generating a plain text file.

**Architecture:** New `exportReport()` method iterating existing QTableWidgets.

**Data collection:** Iterate each visible table (`tblSystem`, `tblProcessor`, `tblGraphics`, `tblMemory`, `tblBattery`, `tblFans`, `tblStorage`) via `item(row, col)->text()`. Hidden sections naturally excluded (0 rows).

**Output format:** Plain text with section headers, key-value pairs, timestamp, app version. Default filename: `nexis-report-YYYY-MM-DD.txt`.

**Flow:** Button click → `QFileDialog::getSaveFileName()` → `QFile` + `QTextStream` write → success message.

**Files:** `hardware_info_page.h/.cpp`, `hardware_info_page.ui`.
